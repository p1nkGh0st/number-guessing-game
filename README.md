# 🎲 Number Guessing Game

A simple, interactive command-line number guessing game built with Python. Challenge yourself against the computer with an arcade-style retro vibe!

---

## 🎮 Game Features
* **Dynamic Feedback:** Generates arcade-style alerts (`TOO LOW!`, `TOO HIGH!`) based on your input.
* **Score Tracking:** Keeps track of how many attempts it took you to crack the number.
* **Input Validation:** Equipped with exception handling. Even if you accidentally type a string/character, the system catches it safely (`NUMBERS ONLY!`) without crashing.


## ❔How to Run

1. Clone this repository or download the `main.py` file.
2. Open your terminal/command prompt and navigate to the project directory.
3. Run the following command:

```bash
python main.py
